CRÉER L'APPLICATION ANDROID (APK) — indépendante de Netlify
============================================================
Une fois l'APK installé sur le téléphone, l'application contient tous ses fichiers :
elle fonctionne même si vous supprimez le site Netlify.

ÉTAPES (environ 15 minutes, gratuit, sans Android Studio) :

1. Créez un compte gratuit sur https://github.com (si vous n'en avez pas).
2. Cliquez sur "+" (en haut à droite) > "New repository". Nom : ouvrage-track. Cochez "Private". Créez.
3. Sur la page du dépôt : "uploading an existing file". Glissez TOUT le contenu de ce dossier
   (dossiers www et .github compris, package.json, capacitor.config.json). IMPORTANT : le dossier
   ".github" doit être envoyé (s'il est caché, activez "afficher les fichiers cachés" sous Windows).
   Cliquez "Commit changes".
4. Onglet "Actions" > "Construire l'APK" > "Run workflow". Attendez 5 à 8 minutes (coche verte).
5. Ouvrez l'exécution terminée > en bas "Artifacts" > téléchargez "OuvrageTrack-APK" (zip) > décompressez : app-debug.apk.
6. Envoyez app-debug.apk aux utilisateurs (WhatsApp, Drive, USB). Sur le téléphone :
   ouvrir le fichier > autoriser "installer des applications de sources inconnues" > Installer.

MISES À JOUR : remplacez www/index.html par la nouvelle version, renvoyez sur GitHub, relancez l'étape 4,
puis redistribuez le nouvel APK (les données du téléphone sont conservées si l'APK est installé par-dessus).

LIMITES :
- Android uniquement (iPhone : impossible sans compte développeur Apple payant).
- Non testé sur un vrai téléphone par moi : testez d'abord sur UN téléphone, surtout
  les exports (PDF, Excel, Word) qui peuvent se comporter différemment dans une application Android.
