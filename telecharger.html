Ouvrage Track

Choisissez votre appareil pour télécharger l'application.

📱 Télécharger pour Android 💻 Télécharger pour Windows (PC)
Installer sur Android
  1. Ouvrez le fichier téléchargé « OuvrageTrack.apk » (notifications ou dossier Téléchargements).
  2. Si Android bloque l'installation : touchez « Paramètres », activez « Autoriser depuis cette source », puis revenez en arrière.
  3. Touchez « Installer ». Si Play Protect propose une analyse, choisissez « Installer quand même ».
  4. Ouvrez « Ouvrage Track » depuis l'écran d'accueil.
Installer sur Windows
  1. Faites un clic droit sur le fichier téléchargé, puis « Extraire tout… ».
  2. Ouvrez le dossier obtenu et double-cliquez sur « INSTALLER.bat ».
  3. Lancez « Ouvrage Track » depuis le bureau.
iPhone / iPad

Il n'existe pas de fichier d'installation pour iPhone. Contactez votre responsable pour obtenir l'accès.
